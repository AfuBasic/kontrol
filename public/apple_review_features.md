# Kontrol - Application Features Overview

This document provides a comprehensive breakdown of the core modules and features currently implemented in the **Kontrol** estate management platform, prepared for App Store Review.

---

## 🏢 Admin Module (Estate Management)
*The centralized command center for estate managers, HOAs, and administrative staff.*

### 👥 Resident Management
- **Approval Portal**: Structured workflow for reviewing, approving, or rejecting new resident applications with automated feedback.
- **Secure Invitations**: Generation of unique, time-limited onboarding links to invite residents directly.
- **Resident Directory**: Filterable database of all residents with status tracking, household details, and contact info.

### 💳 Financial Management
- **Automated Invoicing**: System-generated invoices based on active resident counts and billing cycles (Quarterly, Bi-Annually, Annually).
- **Payment Collection**: Integrated Paystack gateway for secure, automated subscription settling.
- **Financial Audit**: Detailed history of all payment transactions (Successful, Pending, Failed).

### 📢 Communication Hub
- **Estate Board**: Centralized announcement system for broadcasting updates with rich media/image support.
- **Moderation**: Ability to manage resident discussions and engagement on estate-wide announcements.
- **Staff Management**: Dedicated portal to register and monitor gatehouse security personnel.

---

## 🏠 Resident Module (Resident Experience)
*Focuses on security, visitor management, and community engagement for homeowners and tenants.*

### 🛡️ Visitor Management
- **Access Code Generation**: Residents generate secure, 6-digit access codes for their guests directly from the app.
- **Flexible Code Types**: Support for one-time guest codes or recurring access for frequent visitors.
- **Real-time Visit Feed**: Personal history showing guest arrival and departure times at the gate.

### 🗣️ Community Interaction
- **Interactive Notice Board**: Access to estate announcements with the ability to participate in community discussions.
- **Emergency Contacts**: Direct access to estate management and local emergency services (Police, Fire).
- **Household Management**: Add and manage family members under a single primary unit for consistent family access.

### 🤖 Advanced Connectivity
- **Telegram Bot Integration**: Bridge linking the Kontrol account to Telegram for code generation and alerts.
- **Real-time Notifications**: Instant push alerts for guest arrivals and important estate updates.

---

## 🛡️ Security Module (The Gatehouse)
*Streamlined interface for quick action and accurate visitor logging by security staff.*

### 🔍 Validation & Entry
- **Quick Code Scanner**: Dedicated validation tool for guards to instantly verify visitor access codes.
- **Digital Visitor Logs**: Real-time logging of entry/exit times, replacing manual paper-based visitor books.
- **Situational Awareness**: A rolling stream of expected visitors and active check-ins for the gatehouse.
